دفتر ریاضی — تکالیف
۱معادله ۳x + ۷ = ۲۲ را حل کنید.
۳x = ۲۲ − ۷ = ۱۵  ⇒  x = ۵
۲حاصل (۲x + ۳)² − (۲x − ۳)² را ساده کنید.
= (۴x² + ۱۲x + ۹) − (۴x² − ۱۲x + ۹) = ۲۴x
۳ریشه‌های معادله x² − ۵x + ۶ = ۰ را پیدا کنید.
... ؟
توی ماشین دفترم رو باز کردم تا تکالیف رو بنویسم...
📌 یادآوری سر کلاس — معلم ریاضی
برای حل معادله درجه دوم: x² + bx + c = ۰
دو عدد پیدا کن که حاصل‌جمعشان = b
و حاصل‌ضربشان = c باشد.
اون دو عدد، ریشه‌های معادله هستن!
یهو یاد حرف‌های معلم ریاضی افتادم...
دفتر ریاضی — ادامه
۱معادله ۳x + ۷ = ۲۲ را حل کنید.
۳x = ۱۵  ⇒  x = ۵ ✓
۲حاصل (۲x + ۳)² − (۲x − ۳)² را ساده کنید.
= ۲۴x ✓
۳ریشه‌های معادله x² − ۵x + ۶ = ۰
دو عدد: ۲ و ۳ — جمعشان ۵، ضربشان ۶
⇒ (x − ۲)(x − ۳) = ۰  ⇒  x = ۲ یا x = ۳
آها! یادم اومد... جواب x = ۲ یا x = ۳ 🎯
